## Usage

```
import { Modal } from '@console/nimbus-ui/core';
```

## Features

A modal consists of an overlay container element, and an underlay.
The overlay contains a Dialog and the underlay is a transparent element
that covers the rest of the screen behind the overlay, and prevents the
user from interacting with the elements behind it.

- **Styleable** – Customizable animations and styles for overlay, modal, header, content, footer, and close button.
- **Accessible** – Hides content outside, closes on outside click or Escape key.
- **Focus** – Focused inside the modal on mount, returned to trigger on unmount.
- **Scrolling** – Disables page scrolling while modal is open.
- **Header** – Customizable and styleable header section.
- **Footer** – Customizable and styleable footer section for actions.
- **Close Button** – Built-in, styleable close button for dismissing the modal.
- **Dismissable** – Optionally dismissable by close button or outside click.

# API

## Modal

Root component that takes a `Modal.Header`, `Modal.Close`, `Modal.Content` and `Modal.Footer` as children.

```jsx
<Modal>
  <Modal.Close>...</Modal.Close>
  <Modal.Header>...</Modal.Header>
  <Modal.Content>...</Modal.Content>
  <Modal.Footer>...</Modal.Footer>
<Modal>
```
