## Usage

```
import { Radio } from '@console/nimbus-ui/core';
```

## Features

This radio group component simplifies HTML radio group creation with the useRadioGroup and useRadio hooks,
eliminating the complexity of styling issues associated with the `<fieldset>` and `<input>` elements.
The radio and radio group have the following features:

- Radios use native HTML for seamless assistive tech integration with ARIA attributes.
- Compatible with form autofill, validation, and consistent behavior across browsers.
- Easily customize appearance by hiding the HTML `<input>` for full styling control.
- Supports keyboard navigation, horizontal/vertical orientation, and controlled/uncontrolled usage.
- Adheres to WAI-ARIA, maintaining focus management with roving tabindex for compliance.
