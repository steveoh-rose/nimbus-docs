## Features

Checkbox is automatically connected to handle Accessibility features. Checkbox has some features baked in to make it easier to use and more consistent.

- Built with a native `<input>` element
- Visual and ARIA labeling support
- Required and invalid states exposed to assistive technology via ARIA
- Support for description and error message help text linked to the input via ARIA
- Easily customize appearance by hiding the HTML `<input>` for full styling control.
