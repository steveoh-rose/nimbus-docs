ComboBoxes combine a text entry with a picker menu, allowing users to filter longer lists to only the selections matching a query.
ComboBox also supports an optional hint element, used for description and error messages, which can be used to provide more context about the field.

## Features

ComboBox is automatically connected to handle accessibility features.

- Adheres to the [WCAG ComboBox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)
- Visual and ARIA labeling support
- Required and invalid states exposed to assistive technology via ARIA
- Support for description and error message help text linked to the input via ARIA
- Support for mouse, touch, and keyboard input events
- Ability to open the combo box list via arrow keys on the keyboard
- Ability to filter options through text input
- Ability to choose a singular option
- Support for disabled options
- Supports grouping of items into sections
- Adjusts positioning of popover to fit in viewport
