## Usage

```
import { Tooltip } from '@console/nimbus-ui/core';
```

## Features

The HTML title attribute can be used to create a tooltip, but it cannot be styled. Custom styled tooltips can be hard to build in an accessible way.
The following Tooltip is built using `floating-ui`, turning tooltips into fully accessible reusable components.
The tooltip has the following features:

- Dynamic anchor positioning using floating-ui. The tooltip is positioned next to its reference element, and remains anchored to it while avoiding collisions.
- The elements are given relevant role and ARIA attributes to be accessible to screen readers and follow the [Tooltip Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/).
- The tooltip will open on focus and hover events and closes using the escape key.
- Support for custom timings.
- Allows for composable components, allowing custom props for subcomponents.
- Supports ref forwardRef through the `asChild` prop.

# API

## Tooltip

Root component that takes both the `Trigger` and the `Content` as children.

```jsx
<Tooltip>
  <Tooltip.Trigger>...</Tooltip.Trigger>
  <Tooltip.Content>...</Tooltip.Content>
<Tooltip>
```

<ArgTypes sort={'alpha'} of={TooltipStories} />

## Tooltip.Trigger

This is the button that toggles the tooltip. By default, the `Tooltip.Content` will position itself against the trigger.
You can add any element as the trigger. The element will be default be wrapped by a `<span />` tag.

```jsx
<Tooltip.Trigger>Add your tooltip trigger element here</Tooltip.Trigger>
```

