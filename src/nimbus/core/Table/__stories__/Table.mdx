## Features

A table consists of a container element, with columns and rows of cells containing data inside.
The cells within a table may contain focusable elements or plain text content.
If the table supports row selection, each row can optionally include a selection checkbox.
Additionally, a "select all" checkbox may be displayed in a column header if the table supports multiple row selection.

- **Row selection** – Single or multiple selection, with optional checkboxes, disabled rows, and both toggle and replace selection behaviors.
- **Columns** – Support for column sorting and row header columns. Columns may optionally allow user resizing via mouse, touch, and keyboard interactions.
- **Interactive children** – Table cells may include interactive elements such as buttons, menus, etc.
