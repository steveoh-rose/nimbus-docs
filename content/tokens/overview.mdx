Nimbus components never hard-code a color, a font size or a gap. They reference **tokens**, and the tokens live in one place: `cc-design-tokens`. Change a token and every component that uses it follows.

This section documents each token category and the way tokens are consumed.

<TokenCategories />

## One name, three formats

Every token is published as a CSS custom property, a Sass variable and a JavaScript constant, all derived from the same name.

| Format | Example |
| --- | --- |
| CSS | `var(--color-primary-300)` |
| Sass | `$color-primary-300` |
| JavaScript | `colorPrimary300` |

## Naming

Names read from general to specific: `category`, then `group`, then `step`. `--color-primary-300` is a color, in the primary group, at step 300. Steps run from 100 (lightest) to 500 (darkest).

## Deprecated tokens

Some legacy names remain so older code keeps working, each with a note saying what replaces it. For example, `--color-primary-dark` is replaced by `--color-primary-400`. Deprecated tokens are marked on the [color page](/docs/tokens/colors).
