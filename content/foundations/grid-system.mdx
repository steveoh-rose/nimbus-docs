## Breakpoints

Nimbus is responsive by nature and supports display on devices from large desktops to small mobiles, using 3 breakpoints to create 4 grid sizes.

| | Large desktop | Small desktop | Large device | Small device |
| --- | --- | --- | --- | --- |
| **Display width** | `> 1440` | `1439 - 1000` | `999 - 450` | `< 449` |
| **Grid width** | 1370px | 910px | 450px | 100% |
| **Columns** | 12 | 12 | 1 | 1 |
| **Global nav** | Default, top | Default, top | Tablet, top | Mobile, top |
| **Contextual nav** | Default, left | Default, left | Mobile, top | Mobile, top |

### Large desktop

- Minimum width: 1440px
- Grid width: 1370px
- Columns: 12

Use any combination of column widths within a row, adding up to 12.

### Small desktop

- Minimum width: 1000px
- Grid width: 910px
- Columns: 12

Use any combination of column widths within a row, adding up to 12.

### Large device

- Minimum width: 450px
- Grid width: 450px
- Columns: 1

All columns are now 100% width and stacked on top of each other.

### Small device

- Minimum width: 0px
- Grid width: 100% with 10px margins left and right
- Columns: 1

All columns are 100% width and stack on top of each other. Content shrinks in width to match the screen.

## Responsive grid

### How it works

The Nimbus responsive grid system uses containers, rows and columns to lay out and align content. Breakpoints are used to adjust the width of the content so that it is viewable on all devices.

### Parts of the whole

**Main navigation.** The site-level navigation bars and menus sit outside of the container and grid.

**Container.** The container occupies all the remaining space inside the navigation bars that border the top and left sides.

**Responsive grid.** The grid is centred inside of the container. Its width is determined by the screen width. There are 4 widths, detailed in [Breakpoints](#breakpoints).

**Rows.** Rows are containers for columns. The columns within a row will wrap within that row and remain separate from other rows.

**Columns.** Columns are where all the main responsive action takes place. All content is placed inside of columns, and those columns sit inside of rows.

**Gutters.** Gutters are the empty space between columns. These are always 10px.

### Columns

There are 12 columns.

<ColumnRuler />

This allows a nice variety of evenly split layouts:

<ColumnLayouts />

But of course, you can have any combination of columns within a row, so long as the total base column width is 12.

When a column cannot fit horizontally adjacent to the column to the left, the entire column will be wrapped below, increasing the height of the row.

### Responsiveness

To make the grid responsive, there are four breakpoints. When the screen width hits a breakpoint, the grid width is adjusted, and the layout and content follow suit by either also changing width, or wrapping below if it can no longer fit within the row.

### Applying the grid

Structural elements and groups of elements are given a column width that is enforced by the grid. You may choose to have different column widths for the same structure and groups at each grid size.

## Example

In this example there is:

- A header with content aligned left and right. The background is full width, while the content is all contained within the grid.
- 3 tiles.

<GridExample />

**Large desktop.** The header is divided into 2 columns, each 6 base columns wide. The 3 tiles are all 4 base columns wide.

**Small desktop.** The header is still divided into 2 columns and each is still 6 base columns wide. The tiles are now 6 base columns wide, causing them to wrap.

**Small device.** The header is still divided into 2 columns, but each is now 12 columns / 100% wide, causing them to stack. The tiles are also now 12 columns / 100% wide, and the tile background is also full width, while the content is all contained within the grid.

## Implementation

The grid maps directly onto CSS grid. A minimal version, using the values from the table above and the design token spacing for the gutter:

```css
.container {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 10px;
  width: 1370px;
  margin-inline: auto;
}

/* small desktop */
@media (max-width: 1439px) {
  .container { width: 910px; }
}

/* large device: a single column */
@media (max-width: 999px) {
  .container { grid-template-columns: 1fr; width: 450px; }
}

/* small device: fluid, with 10px margins */
@media (max-width: 449px) {
  .container { width: calc(100% - 20px); }
}

.tile { grid-column: span 4; }
```
