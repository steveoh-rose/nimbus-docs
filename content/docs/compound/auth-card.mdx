A common template built from [Card](/docs/components/card),
[Input](/docs/components/input), [Label](/docs/components/textarea), and
[Button](/docs/components/button) — the kind of screen most products need on
day one.

<ComponentPreview name="auth-card" />

## Usage

```tsx
import { Button, Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle, Input, Label } from "@nimbus/ui"

export function SignInCard() {
  return (
    <Card className="w-full max-w-sm">
      <CardHeader>
        <CardTitle>Sign in to Nimbus</CardTitle>
        <CardDescription>Enter your work email below.</CardDescription>
      </CardHeader>
      <CardContent className="grid gap-4">
        <div className="grid gap-2">
          <Label htmlFor="email">Email</Label>
          <Input id="email" type="email" />
        </div>
        <div className="grid gap-2">
          <Label htmlFor="password">Password</Label>
          <Input id="password" type="password" />
        </div>
      </CardContent>
      <CardFooter>
        <Button className="w-full">Sign in</Button>
      </CardFooter>
    </Card>
  )
}
```

## Extending it

Add [form validation](/docs/patterns/form-validation) to this template by
wiring it to a form library and showing field-level errors under each
`Input`, rather than treating it as a new component to build from scratch.
