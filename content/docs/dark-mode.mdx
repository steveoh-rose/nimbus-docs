---
title: Dark Mode
description: Enable and control Nimbus UI's dark theme.
---

Nimbus UI ships light and dark values for every color token, switched via a
`.dark` class on any ancestor element — the same convention used by this
documentation site itself (see the toggle in the header).

## Manual toggle

```tsx
document.documentElement.classList.toggle("dark")
```

## With next-themes

Most Next.js apps should reach for [`next-themes`](https://github.com/pacocoursey/next-themes)
so the theme also respects system preference and persists across reloads:

```tsx
import { ThemeProvider } from "next-themes"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
          {children}
        </ThemeProvider>
      </body>
    </html>
  )
}
```

## Testing both themes

Every component preview on this site can be viewed in either theme using the
toggle in the top-right of the header — there's no separate dark-mode-only
documentation to keep in sync.
