## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@nimbus/ui"
import { TerminalIcon } from "lucide-react"

export function Example() {
  return (
    <Alert>
      <TerminalIcon />
      <AlertTitle>Heads up!</AlertTitle>
      <AlertDescription>You can add components using the CLI.</AlertDescription>
    </Alert>
  )
}
```

## When to use vs. Toast

Use **Alert** for persistent, page-level messages that stay until dismissed
or resolved. Use a toast/notification for transient, time-limited feedback
about an action that just happened.
