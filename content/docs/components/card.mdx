## Usage

```tsx
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@nimbus/ui"

export function Example() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Bandwidth usage</CardTitle>
        <CardDescription>This month across all connections.</CardDescription>
      </CardHeader>
      <CardContent>4.2 TB</CardContent>
      <CardFooter>View report</CardFooter>
    </Card>
  )
}
```

## Composition

`Card` is a slot-based composition, not a single monolithic component:
`CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent`, and
`CardFooter` can be combined or omitted freely depending on content.
