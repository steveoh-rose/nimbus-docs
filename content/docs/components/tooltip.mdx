## Usage

```tsx
import { Tooltip, TooltipContent, TooltipTrigger } from "@nimbus/ui"

export function Example() {
  return (
    <Tooltip>
      <TooltipTrigger>Hover me</TooltipTrigger>
      <TooltipContent>Add to library</TooltipContent>
    </Tooltip>
  )
}
```

A single `TooltipProvider` wraps the app root so every tooltip shares the
same show/hide delay — see `src/app/layout.tsx` on this site for the pattern.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `delayDuration` | `number` | `700` | Hover delay in ms before showing, set on `TooltipProvider` |
| `side` | `top \| right \| bottom \| left` | `top` | Preferred side, on `TooltipContent` |
