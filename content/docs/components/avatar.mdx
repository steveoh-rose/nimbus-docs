---
title: Avatar
description: Represents a user or entity with an image, falling back to initials.
---

Full preview and API reference coming soon. The underlying primitive
(`src/components/ui/avatar.tsx`) is already installed in this scaffold — a
demo just hasn't been written yet.

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@nimbus/ui"

export function Example() {
  return (
    <Avatar>
      <AvatarImage src="/avatar.png" alt="Jane Doe" />
      <AvatarFallback>JD</AvatarFallback>
    </Avatar>
  )
}
```
