## Font stack

Nimbus UI defaults to the system UI stack for body text and a matching
monospace stack for code, keeping bundle size down and rendering native to
each platform. Products can override `--font-sans` / `--font-mono` to bring
in a brand typeface.

## Scale

| Step | Size | Typical use |
| --- | --- | --- |
| `text-xs` | 0.75rem | Captions, badges |
| `text-sm` | 0.875rem | Secondary text, form labels |
| `text-base` | 1rem | Body copy |
| `text-lg` | 1.125rem | Lead paragraphs |
| `text-xl` – `text-2xl` | 1.25–1.5rem | Card/section titles |
| `text-3xl` – `text-4xl` | 1.875–2.25rem | Page titles, hero headings |
