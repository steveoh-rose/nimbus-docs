title: Spacing
description: The base spacing scale used for padding, margin, and gaps.
---

<ComponentPreview name="spacing-scale" />

Nimbus UI uses a 0.25rem (4px) base unit, matching Tailwind's default scale,
so spacing tokens and utility classes stay in lockstep. Prefer the named
scale steps over arbitrary pixel values when composing layouts, so spacing
stays consistent as the token values evolve.
