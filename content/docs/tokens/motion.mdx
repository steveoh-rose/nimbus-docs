Hover the squares above to feel the difference between durations and easing
curves.

| Token | Value | Use for |
| --- | --- | --- |
| `duration-150` | 150ms | Micro-interactions — hover, focus rings |
| `duration-300` | 300ms | Component-level transitions — accordions, tabs |
| `duration-500` | 500ms | Page-level transitions, larger overlays |

Prefer `ease-out` for elements entering the screen and `ease-in` for elements
leaving, with `ease-in-out` as the default for state changes in place (like a
hover scale).
